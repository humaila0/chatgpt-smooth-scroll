# ChatGPT Smooth Scroll

A simple Chrome Manifest V3 extension that adds floating navigation buttons to ChatGPT.

## Features

- Smooth scroll up/down
- Go to top
- Go to bottom
- Keyboard shortcuts
- Automatically detects the ChatGPT scroll container
- No API key
- No backend
- Runs only on ChatGPT

## Install

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Select this folder
5. Open or refresh `https://chatgpt.com/`

## Keyboard shortcuts

- Alt + Up Arrow = scroll up
- Alt + Down Arrow = scroll down
- Alt + Home = top
- Alt + End = bottom

If ChatGPT changes its internal DOM in a future update, the scroll-container detection may need to be adjusted.
